# Portfolio Image Uploads

Place the portfolio images for this site in this folder.

Suggested organization:
- profile/ — profile and personal brand images
- projects/ — project screenshots and product images
- certificates/ — certificates and achievements
- gallery/ — other portfolio/gallery images

You can upload the image files directly into this folder (or its subfolders) from GitHub. The portfolio will use these repository-hosted assets rather than depending on the owner-dashboard upload button.
