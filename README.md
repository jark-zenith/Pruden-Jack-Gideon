# Pruden Jack Gideon

Personal portfolio of Pruden Jack Gideon — showcasing software, AI, web development, projects, and digital work.

## Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- Lucide React

## Development

```bash
npm install
npm run dev
```

Build for production:

```bash
npm run build
```
